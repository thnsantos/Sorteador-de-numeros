# Sorteador de Números

Um sorteador simples e visual para escolher números dentro de um intervalo definido pelo usuário.

## Sobre o projeto

Este projeto foi criado para praticar a construção de uma página interativa. A pessoa informa:

- quantos números deseja sortear;
- o menor número possível;
- o maior número possível;
- se os números podem se repetir.

Depois, basta clicar em **Sortear** para visualizar o resultado com uma animação.

## Como usar

1. Informe a quantidade de números.
2. Escolha o valor inicial do intervalo.
3. Escolha o valor final do intervalo.
4. Marque ou desmarque a opção de não repetir números.
5. Clique em **Sortear**.
6. Para voltar e fazer outro sorteio, clique em **Sortear novamente**.

Os campos precisam ser preenchidos corretamente. O valor inicial também não pode ser maior que o valor final.

## Recursos

- Sorteio de um ou vários números.
- Opção para evitar números repetidos.
- Validação dos campos vazios.
- Resultado apresentado com animação.
- Interface adaptada para a proposta do projeto.
- Botão para realizar um novo sorteio.

## Arquivos principais

- `index.html`: organiza o conteúdo da página e do formulário.
- `styles/`: reúne os estilos visuais do projeto.
- `scripts.js`: controla o sorteio, as validações e a troca entre formulário e resultado.
- `assets/`: contém imagens usadas na interface.

## Como abrir

Abra o arquivo `index.html` no navegador. Não é necessário instalar nada para visualizar o projeto.
